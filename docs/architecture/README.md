## How to regenerate

```sh
# Install archify (one-time)
npx -y skills add tt-a1i/archify --skill archify --agent opencode --global --copy --yes

# Regenerate a diagram
node ~/.agents/skills/archify/bin/archify.mjs finalize architecture docs/architecture/<name>.candidate.json docs/architecture/<name>.html --repo-root . --quality showcase --json
```

## Rules

- Every diagram must cite real source paths (enforced by archify's `--repo-root` validation)
- Diagrams are committed to git — they are architecture documentation, not scratch
- When a spec changes module topology or adds a security boundary, update the relevant diagram in the same spec
- `docs/ARCHITECTURE.md` is generated by `make docs` (module tables + size snapshot) — these diagrams complement it with visual topology
